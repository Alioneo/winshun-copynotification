# 剪贴板通知

复制文字、图片或文件时，桌面右下角会出一张卡片，停一会儿自己消失。卡片不抢焦点，鼠标可以直接穿过去。

特殊功能：当你使用小米手机配小米笔记本或者普通台式机（安装了小米互联服务）时，手机剪贴板和电脑剪贴板就可以同步了。但是手机复制的内容，剪贴板不显示。这个插件补足了这个问题，问题在于 WinShun 的剪贴板历史常常抓不到这次写入，或者抓到的是空的。插件补的就是这个口子：等内容写完，用自己的窗口重写一次剪贴板，历史里就能看到这笔，来源显示 MIClipboard。

插件不缓存复制的内容。图片只在内存里解码，不落盘。只有打开日志时，才在自己的数据目录写 plugin.log，随时可以关掉。

作者：Alioneo · 许可证：MIT · 源码：`https://github.com/Alioneo/winshun-copynotification`

## 安装与启用

需要 WinShun 0.22.0 或更新版本。两种安装方式选一种：

1. 在 WinShun 插件库导入 alioneo.copynotification-0.3.2.wsplugin。
2. 把插件文件夹放到 %LOCALAPPDATA%\WinShun\plugins\alioneo.copynotification\。便携版放进它自己的插件目录。

装好后启用插件，确认三项权限：ui、clipboard:read、clipboard:write。写入剪贴板这项必须给，否则手机内容接力会失败。然后复制一段文字或一张图片，看到右下角卡片就说明工作正常。

这是未审核原生插件。安装和每次更新，WinShun 都会单独要求确认。

## 关键字与示例

在 WinShun 搜索框输入 剪贴板通知，后面加一个空格。列表里会出现一条结果：

- 标题：剪贴板通知已开启
- 下面一行小字：复制文字或图片后会在右下角弹出提示

按 Enter 只是把 WinShun 的命令面板收起来。这条命令不复制任何内容，也不弹卡片，只用来确认插件在运行。想试卡片，直接复制一段文字或一张图片。

匹配只取空格前的第一个词，按原样比较，没有前缀匹配，也没有模糊搜索。必须完整输入 剪贴板通知。剪贴板、通知、气泡 都不会命中。

关键字可以改。WinShun 设置里有插件关键字，换成别的词就行。两个插件默认用同一个关键字时，两边都不会自动命中，得自己留一个。

## 使用

复制文字：卡片显示开头一段文字。
复制图片：卡片显示缩略图。EXIF 方向会先摆正，手机横拍竖拍都不会倒。
复制文件：卡片显示"已复制文件"。

一次复制只出一张卡片。同一内容 30 秒内重复复制不再弹。卡片默认停留 1.5 秒。音效默认开，音量 70。

WinShun 自己写剪贴板时不弹，比如在历史里粘贴、从历史里再复制。插件按进程名忽略 winshun.exe，不自己吵自己。

手机复制的内容见下一节。

## 小米互联接力

手机复制文字后，小米互联一般先发一个通知，内容稍晚才写进电脑剪贴板。插件看到这次写入后开始等，最多重试 12 次，约 5.65 秒。内容到了，就用自己的窗口重写一次剪贴板，让 WinShun 历史能记下来。

两次接力之间至少隔 2 秒。接力进行中，手机再复制的第二笔，不论内容都会被丢弃，不排队。

手机复制图片或文件：等约 5.65 秒，拿不到文字就按普通复制弹卡片。图片出缩略图，超限时退回文件提示。

## 权限

| 权限 | 用途 |
| ui | 显示右下角卡片 |
| clipboard:read | 读取刚复制的内容，判断是文字、图片还是文件 |
| clipboard:write | 手机内容就绪后重写剪贴板；被拒绝时保留原内容，不弹成功提示 |

不申请 network、processes、files:write。插件不联网，不起子进程，不写用户文件。打开日志时只写自己的数据目录。

## 未审核原生插件

本插件通过 WinShun 社区库的未审核原生插件通道发布，条目里标记为 review: unreviewed-native。包内包含 Windows exe。文件检查、哈希和构建记录只能证明包没有被换过，不等于代码审核，也不是安全认证。安装和每次更新都需要用户确认。

## 设置

| 设置 | 默认 | 说明 |
| sound | 开 | 复制时播放提示音 |
| volume | 70 | 音量 0 到 100 |
| ignore_process | winshun.exe | 不弹卡片的写入方，逗号分隔 |
| duration_ms | 1500 | 卡片停留时间，500 到 10000 毫秒 |
| max_width | 380 | 卡片最大宽度，240 到 800 |
| opacity | 100 | 不透明度，30 到 100 |
| thumbnail | 开 | 图片显示缩略图 |
| animation | 开 | 淡入淡出 |
| quiet_window_sec | 30 | 同内容静默时间，0 表示关闭 |
| log | 关 | 写 plugin.log，不记录剪贴板明文 |

数据目录：%LOCALAPPDATA%\WinShun\plugins\alioneo.copynotification.data\。日志只写这里。剪贴板历史在 WinShun 自己的 clipboard.db，插件不保存复制内容。

## 源码与构建

源码仓库：`https://github.com/Alioneo/winshun-copynotification`
版本：0.3.2，标签 v0.3.2，提交号发布后补进本节。
构建记录：GitHub Actions 在推送 v* 标签时构建并打包，Release 附件就是工作流产出的包。

本地构建命令：cargo build --release

产物是 target/release/clipboard-notify.exe。build.rs 调用 Windows SDK 的 rc.exe 写入版本信息，FileDescription 和 ProductName 都是 MIClipboard，剪贴板历史里的来源因此显示为 MIClipboard。找不到 rc.exe 时跳过这段资源，功能不变，来源会显示默认程序名。

发布包只放四个文件：plugin.json、clipboard-notify.exe、README.md、LICENSE。

## 已知限制与未验证项

- 79,990,000 像素的图能处理，首帧约 1.1 秒，内存峰值约 234 MB。超过 80,000,000 像素不生成缩略图，退回文件卡片。
- 文件缩略图上限 50 MB。超过按文件提示，不预览。
- 手机图片和文件要等约 5.65 秒才出卡片。这是等小米互联把内容写完的时间，不是卡死。
- 深色主题下的文字对比、多显示器和非 100% 缩放，没有做真机复核。
- 手机接力的来源判断依赖小米互联的进程名。小米改了进程名，插件可能认不出来，需要更新。
- 未审核原生插件每次安装和更新都要用户确认。
